# ラップデッキ

スマホで使うビートプレイヤー。

- ファイルアプリから曲を読み込み、スマホの中だけに保存する（曲はどこにも送らない）
- ビート / 原曲 / 声のみ を自動で見分けて1曲にまとめる
- テンポ（BPM）と「入り」（ラップが始まる位置）を自動で測り、入りの前に 4・3・2・1 を表示
- DJ モード：レコードを指でこすってスクラッチ、CUT ボタンで音を切る
- 聴くモード：画面を消しても流れ続ける。ロック画面から操作でき、終わったら次の曲へ進む
- ホーム画面に追加すると、電波が無くても使える

ファイル名を `曲名 - ビート.m4a` / `曲名 - 原曲.m4a` / `曲名 - 声のみ.m4a` にしておくと自動でまとまる。
